The modules

Every one opens on a worked example from the course notes, so it drops into the lecture you already give. Most carry a Predict mode that hides the answers, so the class commits before the reveal.

How to use them

In the lecture, and afterwards

Each module opens on a worked example from the course notes and reproduces its published answer, so you can put it on the projector mid-lecture without re-deriving anything. Arrow keys drive the main control and Space runs the animation, which matters when you are standing away from the laptop.
