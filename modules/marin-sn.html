What to notice

  1. The specimen value is optimistic and you never get to use it. Start from a polished specimen and switch on a hot-rolled surface: Se can lose more than half its value before any other correction lands.
  2. Surface finish is usually the biggest single bite, and it gets worse as the steel gets stronger. Push Sut up with a hot-rolled surface and watch ka collapse — strong steel only pays off if you also pay for the finish.
  3. Axial loading has no size effect but a permanent 15% penalty. kb = 1, kc = 0.85. Torsion is harsher still at 0.59.
  4. The finite-life line pivots, it does not just drop. Only the 10⁶ end moves — the 10³ end stays anchored to f·Sut, which the Marin factors never touch. That fixed anchor is exactly why a correction to Se changes the slope and not just the intercept.
